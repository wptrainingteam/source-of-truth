---
title: Turn off rearranging on admin screens
tags: [all]
---

Screen Options on the Dashboard and the post editing screen has a new **Allow screen elements to be rearranged** setting. Turn it off to remove the mover buttons and drag and drop from every box, which cuts out extra tab stops and stops accidental moves on touch screens. It's on by default, so nothing changes unless you turn it off ([#50699](https://core.trac.wordpress.org/ticket/50699)).
