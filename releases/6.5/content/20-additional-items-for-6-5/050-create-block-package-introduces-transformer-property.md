The Create Block package now has a [new transformer property](https://github.com/WordPress/gutenberg/pull/55423). The change offloads customization to templates, providing nearly complete control over how they can be used to create plugins or blocks. As a reminder, The Create Block package generates a project with PHP, JS, and CSS code for registering a block with a WordPress plugin.

**Adoption approach:** review the [create block package documentation](https://developer.wordpress.org/block-editor/reference-guides/packages/packages-create-block/) to get started.
