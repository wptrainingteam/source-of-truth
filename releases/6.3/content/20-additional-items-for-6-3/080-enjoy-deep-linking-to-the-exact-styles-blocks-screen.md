When using the Styles > Blocks section, if you click on an individual block in the editor, you’ll automatically be taken to those specific block settings in the Styles interface. When combined with the Style Book feature from 6.2, this makes for faster and more intuitive editing. 

**Visuals:** [video demo](https://drive.google.com/file/d/1OqzzOZzY7MGV_kcAjP9FIt_s0A3rElGa/view?usp=sharing).

**Adoption approach:** [read about how you can use the Style Book for styling block themes](https://developer.wordpress.org/news/2023/06/the-style-book-a-one-stop-shop-for-styling-block-themes/).

**Key Make Posts/GitHub/Trac Issue(s):** Global Styles: Enable deep linking to the selected block only in the Blocks screen. ([50708](https://github.com/WordPress/gutenberg/pull/50708))
