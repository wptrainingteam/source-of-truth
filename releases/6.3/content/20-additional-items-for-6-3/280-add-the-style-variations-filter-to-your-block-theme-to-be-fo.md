To help folks find block themes with style variations, the style-variations tag has been [added as a filter](https://meta.trac.wordpress.org/ticket/6545) to the Theme Directory. There aren’t many themes [with the tag](https://wordpress.org/themes/tags/style-variations/) yet, so please consider both adding style variations and this tag! 

**Adoption approach:** [Ensure your theme has at least one style variation](https://make.wordpress.org/core/2022/05/03/global-styles-variations-in-wordpress-6-0/), and then add a style-variations tag in your block theme’s style.css file header.

**Key Make Posts/GitHub/Trac Issue(s):** [What’s New for Developers May 2023](https://developer.wordpress.org/news/2023/05/whats-new-for-developers-may-2023/).
