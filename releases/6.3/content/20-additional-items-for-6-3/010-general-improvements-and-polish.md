Providing polish to the experience was a major focus of the 6.3 cycle, resulting in many of the items listed below and many more pulled out as individual highlights. Taken together, the aim is to level up intuitiveness and optionality across the entire editing experience. 

*   Site Logo: set, replace and reset directly from the sidebar to simplify the process of managing a site’s brand directly ([49992](https://github.com/WordPress/gutenberg/pull/49992)).
*   Patterns: choose from a masonry layout in a new full screen modal that offers larger previews ([49958](https://github.com/WordPress/gutenberg/pull/49958), [49894](https://github.com/WordPress/gutenberg/pull/49894)). 
*   Site Editor: add hover animation to site editor canvas to indicate editability ([48575](https://github.com/WordPress/gutenberg/pull/48575)).
*   Site Editor: simplify the template revert snackbar ([50626](https://github.com/WordPress/gutenberg/pull/50626))
*   Site Editor: remove screen flash when deleting templates or template parts for a calmer experience ([48449](https://github.com/WordPress/gutenberg/pull/48449)).
*   Site Editor > Pages: add Paragraph prompt to Post Content when empty to orient folks on where to write. ([50623](https://github.com/WordPress/gutenberg/pull/50623))
*   Site Editor > Templates: redesign the table view for templates ([50766](https://github.com/WordPress/gutenberg/pull/50766)).
*   Site Editor > Templates: update template titles balancing for clarity and brevity ([51428](https://github.com/WordPress/gutenberg/pull/51428)).
*   Site Editor > Templates: update “Home” template name to “Blog home” ([52048](https://github.com/WordPress/gutenberg/pull/52048)).
*   Featured Image block: add aspect ratio, giving you more precise control over how templates display images, including when building grid layouts where you want the featured images to be consistent ([47854](https://github.com/WordPress/gutenberg/pull/47854#top)).
*   Featured Image block: new design for Replace and Remove buttons. ([50269](https://github.com/WordPress/gutenberg/pull/50269))
*   Post Template block: added block spacing and layout controls, making it possible to control the space between posts which was previously handled by Custom CSS ([49050](https://github.com/WordPress/gutenberg/pull/49050)). 
*   Navigation block: enable Loginout block to have the option in a site’s menu ([49160](https://github.com/WordPress/gutenberg/pull/49160)).
*   Image block: Display custom borders on placeholder, making it more obvious the impact of the colors involved when setting a featured image ([49569](https://github.com/WordPress/gutenberg/pull/49569)).
*   Image block: allow dragging-and-dropping images from the inserter to image blocks ([49673](https://github.com/WordPress/gutenberg/pull/49673)).
*   Image related blocks: replace “Image size” with “Resolution” in image size controls. ([49112](https://github.com/WordPress/gutenberg/pull/49112))
*   General interface: display device icon on “preview” and “view” buttons. ([50218](https://github.com/WordPress/gutenberg/pull/50218)).
*   General interface: redesigned dimension controls that take up less space ([50660](https://github.com/WordPress/gutenberg/pull/50660)).
*   General interface: add <ViewLink> component so you can quickly open any published content in a new tab. ([50260](https://github.com/WordPress/gutenberg/pull/50260))
*   Block editor: improve “switch to draft” placement. ([50217](https://github.com/WordPress/gutenberg/pull/50217))
*   Block editor: add prepublish nudge to upload external images ([46014](https://github.com/WordPress/gutenberg/pull/46014)). 
*   Media and Video blocks: update media and video icons. ([49523](https://github.com/WordPress/gutenberg/pull/49523))
*   Block settings: rearrange items to highlight more common actions ([50453](https://github.com/WordPress/gutenberg/pull/50453)).
*   Post Date block: addition of a Post Modified Date variation for the Post Date block that allows users to display the post’s most recent updated date ([49111](https://github.com/WordPress/gutenberg/pull/49111)).
*   Spacker block: adapt flex child controls for Spacer ([49362](https://github.com/WordPress/gutenberg/pull/49362)).
*   Optimize and condense unlinked padding / margin controls ([49264](https://github.com/WordPress/gutenberg/issues/49264#top)).
*   Block variations added to block switcher, providing another option to switch from one variation to another ([50139](https://github.com/WordPress/gutenberg/pull/50139))
*   Group block: show visual cue when dragging a block over an empty Group block to better indicate where something might be placed ([50826](https://github.com/WordPress/gutenberg/pull/50826)).
*   Post content block: removed from inserter in the Post Editor to prevent confusion ([50620](https://github.com/WordPress/gutenberg/pull/50620)).
*   Embed block: margin support added ([39384](https://github.com/WordPress/gutenberg/pull/39384)).
*   Columns/Column block: added support for blockGap allowing you to control block spacing ([49526](https://github.com/WordPress/gutenberg/pull/49526))
*   Post Excerpt block: Add excerpt length control ([44964](https://github.com/WordPress/gutenberg/pull/44964#top))
*   Block Supports: Add text columns (column count) to typography supports ([33587](https://github.com/WordPress/gutenberg/pull/33587))
*   Color palette component: updated to improve readability ([50450](https://github.com/WordPress/gutenberg/pull/50450)).
*   oEmbed: Anghami support added ([49850](https://core.trac.wordpress.org/ticket/49850))
*   oEmbed: Add support for TikTok creator profiles ([55784](https://core.trac.wordpress.org/ticket/55784)).
*   Sticky Position: enabling non-root sticky position ([49321](https://github.com/WordPress/gutenberg/pull/49321)).
*   Writing Flow: allow Escape key to deselect blocks and selection during multiselection. ([48904](https://github.com/WordPress/gutenberg/pull/48904))
