WordPress 7.2 updates jQuery Migrate to 3.6.0, which flags code that relies on features jQuery 4 is expected to remove. jQuery itself isn’t updated in 7.2: the jQuery 4 and jQuery UI updates are planned for 7.3, and jQuery Migrate may be turned off by default around the end of 2027. If your plugin or theme uses jQuery, test it on 7.2 and fix any deprecation notices.

Read more: [Preparing for jQuery 4 with WordPress 7.2](https://make.wordpress.org/core/2026/11/17/preparing-for-jquery-4-with-wordpress-7-2/) ([#60478](https://core.trac.wordpress.org/ticket/60478))
