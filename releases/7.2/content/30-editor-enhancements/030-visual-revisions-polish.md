Visual revisions now show changes to the post title ([#82586](https://github.com/WordPress/gutenberg/pull/82586)), and adjacent inline changes are merged so the differences are easier to read ([#80579](https://github.com/WordPress/gutenberg/pull/80579)). The Global Styles revisions screen also moved to the same DataViews layout used elsewhere in the editor ([#80856](https://github.com/WordPress/gutenberg/pull/80856)). You can also compare revisions in a code diff view from the **Options** menu ([#80314](https://github.com/WordPress/gutenberg/pull/80314)).

Tracking: [Visual Revisions: post-7.0 polish](https://github.com/WordPress/gutenberg/issues/79120) (#79120)
