Improvements across the WordPress experience continue to land in each release. While each of the items below aren’t enough to highlight alone, they each play a role in making WordPress better to use.

*   Command Palette: Add “Template Parts” command to site editor. ([61287](https://github.com/WordPress/gutenberg/pull/61287))
*   Keyboard shortcut: Add a shortcut to create group from the selected blocks. ([46972](https://github.com/WordPress/gutenberg/pull/46972))
*   List Block: [Add block class name to the list block](https://github.com/WordPress/gutenberg/pull/56469#top) to make it easier to style the List block separately from other lists. 
*   List View: collapse non-selected items using a handy new keyboard shortcut (Option-L on Mac, or Alt-L on Windows). ([59978](https://github.com/WordPress/gutenberg/pull/59978))
*   List View: Do not open list view by default on mobile. ([59016](https://github.com/WordPress/gutenberg/pull/59016#to))
*   List View: update spacing of individual items. ([60713](https://github.com/WordPress/gutenberg/pull/60713))
*   Multisite: Clarify edit site flow with “Edit site” opening the Site Editor and “Manage Site” to open up multisite network admin site editing screen ([60977](https://core.trac.wordpress.org/ticket/60977#comment:21))
*   Social Icons: Update Medium icon. ([57073](https://github.com/WordPress/gutenberg/pull/57073))
*   Social Icons: Add Bluesky icon. ([61372](https://github.com/WordPress/gutenberg/pull/61372))
*   Social Icons: Update Reddit social icon to latest brand guidelines. ([59438](https://github.com/WordPress/gutenberg/pull/59438))
*   Site Editor: Display confirmation modal before clearing template customization. ([60119](https://github.com/WordPress/gutenberg/pull/60119)) 
*   Site Editor: Improve the frame animation. ([60363](https://github.com/WordPress/gutenberg/pull/60363))
*   Site Editor: Add create pattern button in patterns page. ([60302](https://github.com/WordPress/gutenberg/pull/60302))
*   Site Editor: Ensure more consistent root padding to ensure content is rendered as expected regardless of where they are inserted or edited. ([60715](https://github.com/WordPress/gutenberg/pull/60715))
*   Site Editor: For synced entities the icon should be purple. ([62024](https://github.com/WordPress/gutenberg/pull/62024))
*   Site Editor: Add block-level Text Alignment UI. ([61717](https://github.com/WordPress/gutenberg/pull/61717))
*   Site Editor: Site Editor: Use site title as a link. ([61258](https://github.com/WordPress/gutenberg/pull/61258#top))
*   Spotlight mode: Limit spotlight mode to the editor. ([58817](https://github.com/WordPress/gutenberg/pull/58817#top))
*   Themes: Don’t display Welcome Guide in a hybrid theme. ([55865](https://github.com/WordPress/gutenberg/pull/55865))
*   Quote block: Button for cite add/remove. ([59073](https://github.com/WordPress/gutenberg/pull/59073)).
*   Writing flow: Remove first empty paragraph on Backspace. ([61889](https://github.com/WordPress/gutenberg/pull/61889))
*   Writing flow: unify split logic so t hat when pasting blocks, the split block is merged with the pasted blocks. ([54543](https://github.com/WordPress/gutenberg/pull/54543))
