After [Script Modules were introduced in WordPress 6.5](https://make.wordpress.org/core/2024/03/04/script-modules-in-6-5/), server to client data sharing was explored but not explored in time for beta 1 for 6.6. 

**Key Make Posts/GitHub/Trac Issue(s):** Read the [initial proposal](https://make.wordpress.org/core/2024/05/06/proposal-server-to-client-data-sharing-for-script-modules/) to add this feature to Core for more information.
