The theme of polish also continues for the Navigation Block. Menu names are now displayed in the List View for easier orientation and, for faster design considerations, a **Clear** option was added to the color picker([68446](https://github.com/WordPress/gutenberg/pull/68446))([68454](https://github.com/WordPress/gutenberg/pull/68454)). 

These updates enabled non-interactive formats for the block, and users can now use the choices from the dropdown menu in the block’s tools bar, like **Highlight**, **Strikethrough**, or **Inline image** ([67585](https://github.com/WordPress/gutenberg/pull/67585)).
