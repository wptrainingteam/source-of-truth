Images used as backgrounds in Cover blocks now come with resolution controls so that you can change their sizes. This works with both an uploaded background image or the already assigned featured image. This adds to the more granular control for designers and theme developers. ([#67273](https://github.com/WordPress/gutenberg/pull/67273)), ([62926](https://github.com/WordPress/gutenberg/pull/62926)).
