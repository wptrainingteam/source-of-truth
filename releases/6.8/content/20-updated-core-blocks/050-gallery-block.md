Each image in a Gallery block shows multiple options on how a link should behave and how a visitor to the site can interact with the images. For WordPress 6.8 contributors added **Expand to click** to the Gallery’s toolbar to open all images in a light box effect, with one click. The option is available from the **Link** toolbar button ([64014](https://github.com/WordPress/gutenberg/pull/64014)).
