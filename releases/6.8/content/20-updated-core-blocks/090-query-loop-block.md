For Pages, content creators will find two additional sorting options: **Ascending by order** and **Descending by order**, which allows for a display following the page attribute page\_order ([68781](https://github.com/WordPress/gutenberg/pull/68781)).

Looking to replace your Query Loop block’s design? The Query Loop block patterns have been relocated from a modal to a dropdown. It’s still in the block toolbar, now under **Change design** ([66993](https://github.com/WordPress/gutenberg/pull/66993)).

The Query Loop block now has a new option to **ignore** sticky posts. When selected, the Query Loop block ignores whether a post has the sticky option enabled. When used, all posts show based on the **ORDER BY** preferences selected without taking the sticky status into account. ([66221](https://github.com/WordPress/gutenberg/issues/66221)) ([69057](https://github.com/WordPress/gutenberg/pull/69057))

The Query Loop block can get pages from all levels. Contributors added an attribute to just display the top level pages. Currently, users can only set _`“parents”: [0]`_, via the code editor. There’s no easy option in the user interface yet.
