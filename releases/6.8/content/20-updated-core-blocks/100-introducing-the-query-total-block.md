You know how many results are in your queries, but do your site’s readers? The new [Query Total block](https://github.com/WordPress/gutenberg/pull/67629) is here to help.When added to a Query Loop block, the Query Total block displays the number of results the query has returned, or, alternatively, the current range in a set of paginated results. Out of the box, the new block [shows its border controls](https://github.com/WordPress/gutenberg/pull/68323) ([68150](https://github.com/WordPress/gutenberg/pull/68150))([68323](https://github.com/WordPress/gutenberg/pull/68323)) ([68507](https://github.com/WordPress/gutenberg/pull/68507)).
