In WordPress 6.8, work continues on improvements to the Block Hooks API.

The Block Hooks API now supports dynamically inserting blocks into post content. ([67272](https://github.com/WordPress/gutenberg/pull/67272)) A typical example would be a plugin that provides blocks that can be used in posts and that would like to provide extensibility for those blocks. The Block Hooks API will now also work with Synced Patterns. ([68058](https://github.com/WordPress/gutenberg/pull/68058))
