---
title: Updates to existing blocks
slug: updates-to-existing-blocks
---

For WordPress 6.9, contributors standardized most blocks’ Inspector settings to use the [ToolsPanel component](https://wordpress.github.io/gutenberg/?path=/docs/components-toolspanel--docs), bringing visual consistency across the editor. The shift grants users granular control over displayed settings while simplifying how developers inject additional options into existing groups. The ToolsPanel aligns Inspector controls with the Styles sidebar, already leveraging the component extensively, creating a cohesive authoring experience. ([67813](https://github.com/WordPress/gutenberg/issues/67813))
