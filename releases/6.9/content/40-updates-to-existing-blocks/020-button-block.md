title: Button Block
slug: button-block
tags: [end user, siteadmin]
---

Button Block now sports HTML element selection in **Advanced** settings, letting creators choose between semantic <a> links and true <button> elements. This tackles accessibility headaches where users mistakenly treat buttons as links, confusing screen readers. The dropdown educates users about proper usage, empowering developers and non-coders alike to build accessible interfaces without custom code ([70139](https://github.com/WordPress/gutenberg/pull/70139)).
