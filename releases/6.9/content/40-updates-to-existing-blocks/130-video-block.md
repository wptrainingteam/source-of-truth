The Video Block can now handle multiple language tracks with the option to set one as the default track. It’s also possible to add a poster image to the video block to improve accessibility for visitors with slow internet connections ([71039](https://github.com/WordPress/gutenberg/pull/71039)) ([70939](https://github.com/WordPress/gutenberg/pull/70939))([70227](https://github.com/WordPress/gutenberg/pull/70227)).
