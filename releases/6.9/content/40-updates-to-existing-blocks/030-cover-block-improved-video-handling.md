The Cover Block now supports poster images for videos, enhancing accessibility for users with slow internet or mobile devices. These images can be easily added by dragging and dropping the file onto the Poster Image control, streamlining the post creation process ([70816](https://github.com/WordPress/gutenberg/pull/70816)) ([71039](https://github.com/WordPress/gutenberg/pull/71039))  ([70939](https://github.com/WordPress/gutenberg/pull/70939)).
