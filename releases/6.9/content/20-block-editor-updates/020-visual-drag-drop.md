Drag-and-drop just got smarter. Blocks now show live visual feedback as you reposition them, making layout building more intuitive and precise. You’ll see exactly where elements land before releasing, accelerating the creative process. ([67470](https://github.com/WordPress/gutenberg/pull/67470)). Currently, this only works for single blocks. Drag and Drop of multiple blocks is slated for WordPress 7.0.
