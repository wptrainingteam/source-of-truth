WordPress now makes managing allowed blocks simpler with a new UI tucked in **Advanced** settings. Previously, developers had to edit block markup directly in code view—not user-friendly. This updates makes things easier for website admins, theme builders, and agencies enforcing specific block rules in patterns and templates. While agencies already handled this via code, the new interface offers a nicer interaction model. It’s part of WordPress’s broader mission: letting users build complex sites without touching code at all.  ([72191](https://github.com/WordPress/gutenberg/pull/72191))
