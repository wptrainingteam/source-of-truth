The Time to Read block, available in the Gutenberg plugin for a long time went through an extended accessibility review before it was added to WordPress Core. 

It now has a toggle control to display a range of time rather than a fixed average reading time. It also comes with a variation to display a word count for the post or page it’s used on ([71606](https://github.com/WordPress/gutenberg/pull/71606)) ([71841](https://github.com/WordPress/gutenberg/pull/71841)).
