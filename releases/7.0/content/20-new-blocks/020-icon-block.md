---

The new Icon block empowers users to add decorative icons from a curated collection to their content. It utilizes a new server-side SVG Icon Registration API, ensuring icon registry updates propagate without block validation errors. 

The initial release is limited as it doesn’t yet allow registering third-party icon collections. Extensibility for third-party icon registration is planned for future release in 7.1, following further development on the Icon registry API architecture. A REST endpoint at `/wp/v2/icons` supports searching and filtering. The initial set draws from the `wordpress/icons` package ([71227](https://github.com/WordPress/gutenberg/pull/71227), [72215](https://github.com/WordPress/gutenberg/pull/72215), [75576](https://github.com/WordPress/gutenberg/pull/75576)).
