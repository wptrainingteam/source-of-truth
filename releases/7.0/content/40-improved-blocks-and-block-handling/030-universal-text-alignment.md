---
title: Universal Text Alignment
slug: universal-text-alignment
tags: [all]
---

Nearly all text blocks now support the standardized text-align block support system, including Paragraph, Button, Comment blocks, Heading, and Verse. Plus, text justify alignment is now available. See [tracking issue](https://github.com/WordPress/gutenberg/issues/60763) to follow along on the progress ([60763](https://github.com/WordPress/gutenberg/issues/60763)).
