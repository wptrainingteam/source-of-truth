The ability to set a link as “nofollow” has been added to the available link control options for built in support of a standard practice for more advanced SEO efforts that’s [recommended by major search providers as a way of qualifying outbound links](https://developers.google.com/search/docs/crawling-indexing/qualify-outbound-links).
