Improvements across the WordPress experience continue to land in each release. While each of the items below aren’t enough to highlight alone, taken together they represent a step forward in the overall refinement of blocks, the Site Editor, and Block Editor as a whole:

Blocks:

*   Preformatted: add margin and padding support. ([45196](https://github.com/WordPress/gutenberg/pull/45196))
*   Social Links: add Threads Icon. ([52685](https://github.com/WordPress/gutenberg/pull/52685))
*   Social links: add X icon ([54092](https://github.com/WordPress/gutenberg/pull/54092)).
*   Verse: enable line breaks. ([52928](https://github.com/WordPress/gutenberg/pull/52928))
*   Details:  add block gap support. ([53282](https://github.com/WordPress/gutenberg/pull/53282))
*   File: add margin and padding support. ([45107](https://github.com/WordPress/gutenberg/pull/45107))
*   Column: add stretch alignment ([53325](https://github.com/WordPress/gutenberg/pull/53325#top)).
*   Image: keep image size upon replacing an image ([49982](https://github.com/WordPress/gutenberg/pull/49982#top)).
*   Buttons: allow using a button element for button blocks ([54206](https://github.com/WordPress/gutenberg/pull/54206#top)) .
*   Post Content: add block gap support ([54282](https://github.com/WordPress/gutenberg/pull/54282)).
*   Post Content: add color control support [(51326](https://github.com/WordPress/gutenberg/pull/51326)).
*   Footnotes: Add link, background, and text color support ([52897](https://github.com/WordPress/gutenberg/pull/52897)).
*   Footnotes: Add typography, dimensions, and border block supports ([53044](https://github.com/WordPress/gutenberg/pull/53044)).

Site Editor focused:

*   Patterns: add a sticky header and pagination to make browsing patterns more user friendly ([52663](https://github.com/WordPress/gutenberg/pull/52663#top)).
*   Site Editor: add ability to switch templates when working on a page ([51477](https://github.com/WordPress/gutenberg/pull/51477)).
*   Template parts: add more details to the template part panel ([52476](https://github.com/WordPress/gutenberg/pull/52476#top)).
*   Remove “post” from block titles, simplifying each block name ([53492](https://github.com/WordPress/gutenberg/pull/53492#top)).
*   Global Styles: Introduced a reset to default global styles revision ([52965](https://github.com/WordPress/gutenberg/pull/52965)) and reduced the visibility check from two to one revision ([53281](https://github.com/WordPress/gutenberg/pull/53281)).
*   Update the confirmation notice when applying a style revision over unsaved changes for consistency with other confirmation notices ([52972](https://github.com/WordPress/gutenberg/pull/52972#top)).
*   Global Styles: Update Block specific CSS label to include additional instructions ([49626](https://github.com/WordPress/gutenberg/pull/49626#top)).
*   Theme Previews: Make the back button customizable. ([54242](https://github.com/WordPress/gutenberg/pull/54242))
*   Top Toolbar/Post Editor: Make order of pinned items consistent with the Site Editor ([53908](https://github.com/WordPress/gutenberg/pull/53908#top)).

Media: Add a MIME type exception for .docx generated by Google Docs (trac [57898](https://core.trac.wordpress.org/ticket/57898)).
